# بثوث احترافي

صفحـة ويب احترافية لبث مباشر جاهزة للعرض.

## الملفات

- `index.html` — الصفحة الرئيسية
- `styles.css` — تصميم وتخطيط الصفحة
- `script.js` — تفاعل بسيط مثل حالة البث والعداد

## طريقة التشغيل

1. افتح `index.html` في المتصفح.
2. أو استخدم خادم محلي مثل Live Server في VS Code.

## تخصيص

- يمكنك استبدال قسم الفيديو بـ iframe ببث مباشر من YouTube أو أي خدمة بث أخرى.
- عدّل النصوص والألوان في `styles.css` لتتناسب مع علامتك التجارية.
