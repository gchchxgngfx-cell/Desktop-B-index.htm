# بثوث احترافي

صفحـة ويب احترافية لبث مباشر جاهزة للعرض.

## الملفات

- `index.html` — الصفحة الرئيسية
- `styles.css` — تصميم وتخطيط الصفحة
- `script.js` — تفاعل بسيط مثل حالة البث والعداد

## طريقة التشغيل

1. افتح `index.html` في المتصفح.
2. أو استخدم خادم محلي مثل Live Server في VS Code.

## نشر على GitHub Pages

1. أنشئ مستودع GitHub جديد.
2. انسخ كل الملفات من هذا المجلد إلى المستودع.
3. فعّل GitHub Pages في إعدادات المستودع واختر الفرع `main` أو `gh-pages`.
4. افتح الرابط الناتج من المتصفح على هاتفك ثم اختر "إضافة إلى الشاشة الرئيسية" أو "Install".
5. بهذه الطريقة سيصبح الموقع تطبيقًا قابلًا للتنزيل على الجوال والكمبيوتر.

## تخصيص

- يمكنك استبدال قسم الفيديو بـ iframe ببث مباشر من YouTube أو أي خدمة بث أخرى.
- عدّل النصوص والألوان في `styles.css` لتتناسب مع علامتك التجارية.
